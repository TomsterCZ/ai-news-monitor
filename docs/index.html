Lazare, veni foras: Reprogramming Dormant Neurons to Backdoor AI Agents

Microsoft researchers disclosed 'Lazarus,' a technique that reprograms dormant neurons inside an AI model to plant a hidden backdoor, causing an otherwise normal AI agent to execute malicious commands once a hidden trigger appears. The risk is especially serious for agents with tool or terminal access, where a triggered model could quietly download and run attacker code.

Why it matters: Highlights a new class of hidden vulnerability in agentic AI systems just as companies give agents more autonomy and system access.
