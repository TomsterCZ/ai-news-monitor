Lazare, veni foras: Reprogramming Dormant Neurons to Backdoor AI Agents

Microsoft researchers discovered "Lazarus," a backdoor technique that reprograms dormant neurons in an AI model so that an otherwise normal AI agent executes malicious commands when a hidden trigger appears. The threat is especially serious for agents with tool or terminal access, which could be made to quietly download and run attacker code.

Why it matters: It exposes a new class of hidden vulnerability in AI agents with real-world system access, raising the bar for how models must be vetted before deployment.
