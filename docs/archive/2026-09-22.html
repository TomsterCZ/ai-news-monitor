Jev introduces a new shape of LLM - System One, aka Decision Models

TypeSafe AI unveiled Jev, an example of a new model category it calls "System One models," which some are calling "decision models." Unlike a typical LLM, Jev takes unstructured text as input but outputs floating-point numbers representing categories, yes/no answers, ratings and confidence scores rather than text, effectively working as a frontier-intelligence function call.

Why it matters: It proposes a distinct model shape optimized for structured, typed decisions rather than open-ended text generation, which could open a new product category for production AI systems.
