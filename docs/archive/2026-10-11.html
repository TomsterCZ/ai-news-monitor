AI coding agents generate more code, but not more software

A study found that while AI coding agents let developers produce more code, those efficiency gains get 'absorbed' by the human code-review process, which remains a bottleneck. As a result, the overall output of working software doesn't rise proportionally with the amount of code generated.

Why it matters: It's evidence against the assumption that AI coding tools straightforwardly multiply software output, pointing instead to review and integration as the real constraint on engineering productivity.
